## ✦ Projects

### ArtyFacets: Music Workshop Booking Platform

A full-stack platform where people discover and book music workshops across 100+ events, with 99% data consistency. RESTful APIs for booking, authentication and workshop management respond in under 200 ms, and a server-side rendered Next.js frontend loads pages 35% faster than client-side rendering.

`Next.js` `React` `TypeScript` `Node.js` `Express.js` `MongoDB`

[Live site](https://www.artyfacets.com/) &nbsp;·&nbsp; [Source code](https://github.com/laharivenkatesh/ArtyFactes)

### CampusWhisper: Real-Time College Chat

A real-time chat platform for college-specific and cross-college conversations, built on an event-driven WebSocket architecture for low-latency messaging across many simultaneous sessions. Every message self-destructs after five minutes, so there is zero long-term data retention.

`MongoDB` `Express.js` `React.js` `Node.js` `WebSockets`

[Live site](https://campus-whisper.vercel.app/) &nbsp;·&nbsp; [Source code](https://github.com/laharivenkatesh/CampusWhisper)

### Smart Connect: LinkedIn Networking Assistant

A Chrome extension that reads a LinkedIn profile straight off the page and drafts a personalised outreach or referral message with an LLM. Content scripts pull profile data from the DOM, Chrome runtime messaging connects the popup to those scripts, and OpenRouter generates messages tailored to the networking goal.

`JavaScript` `Chrome Extensions API` `OpenRouter API`
